# Changelog

## 0.5.0

- Adds an optional SFSE Menu Framework settings page with live controls and explicit saving.

## 0.4.1 - 2026-07-16

Initial public release.

- Makes positive boostpack fuel recharge consume configurable player O2.
- Preserves Starfield's native fuel bar, pack types, perks, and tap/hold controls.
- Protects a configurable percentage of the player's live O2 capacity.
- Allows free recharge in sealed interiors and breathable atmospheres.
- Prevents boost activation while the spacesuit is hidden, including with press-and-hold controls.
- Adds no plugin records, Papyrus scripts, load-order entry, or save data.
